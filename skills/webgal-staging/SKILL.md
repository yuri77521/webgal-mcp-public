# WebGAL 演出

先确定玩家在哪一拍应该看到什么变化，选下面最能解释这项变化的一页。Creator 或 Editor 已读到该主题时，直接用已有内容生成脚本。能确定命令、对象、触发时机和预期画面就结束读取。只有尚未解决的具体问题会改变写法时，才加读对应页。例如，台词分两页可以只是反应的时间点，只有分页本身出问题才查文字页。

根据题面给演出建议时，沿下表的已知路径取资料。工程搜索留给需要定位的具体事实，例如实际使用的立绘 ID 或旧转场设置；用户已给出这些事实时直接采用。请区分预期画面与亲眼看过的画面。

| 当前问题 | 按需阅读 |
| --- | --- |
| 角色靠近、换表情跳位、镜头露边、人物与背景光色不合 | [立绘与构图](references/figure-and-composition.md) |
| 黑场、换景残留、动画互相打断、手点后时序失常 | [转场与时序](references/transitions-and-timing.md) |
| 长句在回想里完整，或配音、姓名与分页对不上 | [文字与分页](references/text-and-pagination.md) |
| 主主题页未覆盖的命令、参数或版本差异会影响做法 | [4.6.7 相容性](references/engine-compatibility.md) |
| 要安排实机抽查、比较已有截图或复查失败原因 | [画面抽查](references/visual-validation.md) |

单独咨询时交付镜头建议、原因和检查点。制作新作由 [Creator](../webgal-creator/SKILL.md) 审核剧本与素材；修改已有游戏由 [Editor](../webgal-editor/SKILL.md) 从已保存场景定位、出 diff，完成 Terre 交接及正式计划审批。选材交给 Librarian；模型的动作与表情由 [Live2D](../webgal-live2d/SKILL.md) 核对。演出建议本身不产生工程写入。

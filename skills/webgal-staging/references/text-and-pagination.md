# 正常阅读页的诊断

Creator 或 Editor 的主入口已有普通分页规则。此页用于处理具体故障。

| 症状 | 怎样定位 | 局部修正 |
| --- | --- | --- |
| 回想完整，画面缺了末句 | 用同一候选和模板关 AUTO，看末字渐显完成后的正常文本框。对照该页实际字号、头像占宽、显式换行、行高和控制列。 | 在完整意义或叙述停顿处分成两个手动页。分别看两页首末字，再拼回整段。 |
| 中文长度合适，英文或注音仍出框 | 观察最长、不易折行的词组和注音上缘，保留空格；样式控制符与实际可见文字分别核对。 | 在词组前后寻找自然停顿，保留人名和词组完整。用作者选定的字体与画幅复看。 |
| 一句拆成多页，声音被截或反应太早 | 区分录音对应的范围、每页的说话者和触发反应的最后一页。手点一次较快、一次等声尾，检查实际播放和表情。 | 开头短录音绑定在相应一页；整句录音若在正常翻页时被截，说明当前限制，使用可用且获准的分句音频或调整该段页界。 |
| 文字总数相等，说话者仍然不对 | 从最终 TXT 逐页读回已解析的正文及有效姓名，核对角色对白转入无名旁白或心声的边界。 | 修正姓名继承或清名；对白跨页时保留原有的开、闭引号位置。 |

在审过的片段内记录第一个不同字符或第一处遮挡，修复后只复查该页及相邻页。对未实际打开的字体、模板、窗口尺寸保留未验状态。

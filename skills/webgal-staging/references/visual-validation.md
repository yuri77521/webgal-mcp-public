# 画面抽查

每次先写一个可见的预期，例如「来客听完末页才微笑，右肩位置连续」。从能建立原状态的上一句开始，默认抽查改变的节拍。沿用当前 Creator 或 Editor 的候选、保存版本和预览授权。正式工程的写入仍走原工作流。

| 风险 | 最少应看见什么 |
| --- | --- |
| 分页或姓名串页 | 关 AUTO，等末字完全显现；对照正常画面首末字、姓名框、控制列，再手点一页。 |
| 换表情或重新进场 | 对照变更前后同一身体标志点、其他角色和说话者；涉及退场时，加看一页明确缺席的对白。 |
| 淡化、黑场、移动中断 | 连续看变化过程。通常留起点与终点；闪帧、过冲、短黑场或残留需看中途。对中途翻页的问题，按同一时机再操作一次。 |
| 环境光或天气切换 | 比较最后一个旧场画面和新场第一句，看本该消失的雨、旧人影和偏色，确认应保留的层还在。 |

亲自查看选中的截图，在观察记录里写明场景、台词、使用的模板和看见的具体结果。硬切看第一张发生变化的帧。涉及重新入场时，先确认原 ID 已移除，再看一次缺席页和回场后的站位；仅凭空画面无法判断隐藏对象是否已移除。

每失败一次，在已有交接或私有验收记录末尾追加一行「轮次／尝试的写法／哪一帧仍出了什么问题／允许改哪些语句」。下次修订沿用全部失败行，从相同前置状态局部回归。只有前提发生变化才重试已失败的写法，并注明变化。通过后在末尾记下通过的检查点。画面不可用时保留待验状态；只在用户明确要求完整验收时通关一次。

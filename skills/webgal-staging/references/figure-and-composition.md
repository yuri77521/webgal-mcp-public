# 立绘与构图

以下移动与差分示例适用原版 4.6.7 的普通 PNG。目标人物已入场、移动已结束、两张图画布与留边一致时，可直接据此生成候选。

先确认谁在场、站在哪里、观众此刻应看谁。给建议时采用题面描述的站位。编辑保存场景时从触发页往前核对，有分支只沿能到达该页的路径追踪。遇到跨页移动、换图或重入，可在草案旁记一行「页末／人物 ID 与槽位／已到或正在去的位置、缩放／下次变化」。同名角色可能用了不同对象，显示名不能代替画面 ID。

| 演出意图 | 怎样安排 | 看什么 |
| --- | --- | --- |
| 一个人走近另一个人 | 指向移动者的 ID；匿名立绘指向当前槽位。结合双方槽位原点和活动偏移，选一个仍能看清两人轮廓的终点。普通单段位移的 x 是相对该槽位的目标偏移。 | 前一页建立原站位；移动时另一人及背景保持稳定。 |
| 听完后变表情 | 对方最后一页仍保持原表情，玩家手动翻过该页才换图。已在场的普通静态图片优先用 `changeFigureDiff` 指向同一 ID 或槽位。完整换造型或换装用 `changeFigure` 时，明确带回当前槽位、ID 和所需构图。 | 比较翻页前后同一肩点或眼线，确认换图后人物仍在移动后的落点，旁人也在原位。图片尺寸相同也可能因为透明留边不同而跳动。 |
| 离开后回来 | 告别时仍在场，下一拍按活动 ID 清除。匿名对象清对应槽位。重入时明确图片、身份、槽位、缩放及可见性。 | 告别、缺席、回来三页各自能看出谁在场。 |
| 观众逐渐注意到某人 | 先决定是否需要换景别。全景一起移动可对 `stage-main` 构图；单独移动背景用 `bg-main`。人物走动和整台推近各有各的目标。 | 留头顶和视线方向的空间，检查字幕区。按背景真实裁切余量检查四边；旋转或有过冲的缓动也看中途四角。 |

写成脚本时，普通 PNG 的单段靠近可用 `setTransform:{"position":{"x":-120}} -target=visitor -duration=240 -keep -next;`，按素材和实际 ID 替换。两页台词各自手动停页；末页之后用 `changeFigureDiff:smile.png -id=visitor -next;` 接到角色的回应。对本例，屏幕上的同一肩点就是位置连续性的检查点。

同一室内先看主光方向、脸部亮度和肤色，再决定改背景还是某个角色。一次小调一个目标的亮度或饱和度，并记下离开当前光线时要恢复的值。回忆或逆光允许有叙事目的的色差。构图数字从目标素材校准，每套 PNG 或模型的画布和身体基准都可能不同。
